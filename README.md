The original Raspberry Pi-controlled implementation of the shift-register-based arithmetic unit on the Tang Nano 9K: "Arithmetic (from Shift Registers) Using the Tang Nano 9K FPGA Board" — https://www.youtube.com/watch?v=qTdrYL4ayPM The SIPO A/B, PIPO C, and command decoding logic in this project is a port of the original design shown in the video above, with the Raspberry Pi replaced by an STM32 Blue Pill.
